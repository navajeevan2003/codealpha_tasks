# CodeAlpha Portfolio

A modern responsive personal portfolio website created for the CodeAlpha internship.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Animations
- JavaScript DOM Manipulation

## Main Academic Projects

### 1. GeneCure AI

**AI-Driven CRISPR Disease Gene Target Finder**

Technologies:

- Artificial Intelligence
- Machine Learning
- CRISPR-Cas9
- Bioinformatics

An academic AI-driven system designed to identify and prioritize disease-associated gene targets for CRISPR-Cas9 research.

---

### 2. Edge AI Based Predictive Maintenance System

**Deep Learning-Based Predictive Maintenance**

Technologies:

- Edge AI
- Deep Learning
- IoT
- Predictive Maintenance

An academic Edge AI system designed to predict potential equipment failures by analyzing equipment and sensor-related data using deep-learning techniques.

## Features

- Responsive portfolio
- Hero section
- About section
- Skills section
- Academic projects section
- Project detail modals
- Slide-up modal animation
- Glassmorphism UI
- Dark/light mode
- Mobile navigation
- Scroll reveal animations
- Active navigation highlighting
- Contact form UI
- Escape-key modal closing
- Outside-click modal closing

## Project Modal

Each academic project has a:

**View Details →**

button.

The project details open inside a dark glassmorphism modal with a slide-up animation.

No GitHub, Demo or Report buttons are included.
